# v1.0.0 - Initial Public Research Compendium

This release contains the first public Materials ML Failure Analysis research compendium
by Joseph Maxwell.

It includes:

- three papers on descriptor dependence, model viability, and evidence/engineering authority;
- the Geatomica programme monograph;
- the public Evidence-State Runtime Technical & Industrial Companion;
- selected accepted evidence and replay artefacts;
- minimal publication-specific scripts that reconstruct principal reported claims.

The production Systemica/Geatomica runtime and reusable implementation machinery are not
included.

Archived at: https://doi.org/10.5281/zenodo.21919563
