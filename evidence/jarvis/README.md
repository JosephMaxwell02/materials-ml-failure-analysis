# JARVIS Public Evidence Summary

The source census and fitted common cohort are distinct objects. The reported tabular
route used a 23,824-record common cohort from a 75,993-record source census. Replay was
scientifically equivalent at the frozen tolerance, while 60 of 192 files were raw-byte
divergent. This is local replay evidence, not external validation and not a local
reproduction of the provider's DFT calculations.
