# Public Reproduction Audit

The public analyses are intentionally small, standard-library scripts operating on
derived accepted-result CSV/JSON files. They contain no fitting, model factory,
perturbation engine, recovery controller, orchestration, worker routing, memory backend,
authority transition or source adapter.

Scope is claim inspection, not turnkey replication of the private production service.
Failure of any script or mismatch against a frozen headline is a release hold.
