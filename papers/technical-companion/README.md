# Public Technical and Industrial Companion

This folder contains the current public A4 PDF and publication source of
**Evidence-State Runtime: Public Technical & Industrial Companion V1.5**.

The object remains intentionally implementation-bounded. Its publication source
contains only the disclosed document surface; private implementation details, the
V1.1 source-grounded dossier and older companion versions are excluded. Inclusion of
the source does not license or disclose the production Systemica/Geatomica runtime.
